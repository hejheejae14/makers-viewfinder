# Viewfinder 기능 명세

노션 기능 명세 DB를 저장소에 옮겨 둔 요약본입니다. 기능 번호는 `src/features/<기능번호>` 폴더 이름과 같습니다.
기능별 자세한 내용은 노션 기능 명세 DB의 각 페이지가 기준이고, 이 문서와 다르면 노션을 따릅니다.

## 한 줄 요약

메이커스 디자이너가 검색어 하나로 기존 화면과 그 화면에 얽힌 맥락을 한곳에서 찾고, 이어서 필요한 작업으로 바로 넘어갈 수 있도록 하는 디자인 탐색 도구

## 전체 흐름

1. 처음 사용할 때 팀 비밀번호와 개인 AI API 키를 입력한다.
2. 팀을 선택하고, 화면이나 기능을 검색한다. (예: 플그 선택 > 커뮤니티 댓글 언급 기능 찾아줘)
3. AI가 검색 인덱스에서 화면을 찾아, 찾은 화면에 대한 정보와 원본 링크를 제공한다.
4. 다음 액션으로 이어간다. 서비스 안에서 처리하기 어려운 작업은 각자의 Claude/ChatGPT로 이어서 할 수 있도록 한다.

## 만드는 방식

- 웹 형태의 프로덕트로 만든다.
- 디자인 원본은 저장하지 않고, 검색 인덱스(화면 이름, 화면 속 텍스트, 컴포넌트, 원본 링크)만 저장한다.
- AI는 사용자가 각자 입력한 API 키(BYOK)로 쓴다.
- 내부 화면 정보가 외부에 노출되지 않도록 웹 접속은 팀 공용 비밀번호로 잠근다. 필요해지면 Google 로그인으로 바꾼다.
  - 비밀번호 값은 저장소에 올리지 않는다. 서버 환경 변수 `TEAM_PASSWORD`로만 관리하고, 값은 팀 채널에서 공유한다.
- 깃허브 저장소 하나와 공통 프로젝트 지침(`AGENTS.md`)을 함께 쓰고, 기능 단위로 담당자를 정한다.
