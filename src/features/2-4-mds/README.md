# 2-4. MDS 컴포넌트·토큰 표시

찾은 화면에 쓰인 MDS 컴포넌트와 토큰을 보여줍니다. (IndexedScreen.components, tokens)

- 노션 기능 명세 DB의 "2-4. MDS 컴포넌트·토큰 표시" 페이지를 참고합니다.
- 이 기능의 코드는 이 폴더 안에 둡니다.

## 구현 및 확인

`MdsUsage`에 `screen: IndexedScreen`을 전달합니다.
`isMds`가 참인 컴포넌트의 이름·변형·버전·라이브러리와 중복을 제거한 토큰을 표시합니다.
버전과 변형이 없으면 추측하지 않고 정보 없음으로 표시합니다.
요소 정보가 미제공된 경우와 빈 배열로 MDS 없음이 기록된 경우를 구분합니다.

`/preview/design-details`에서 2-3과 함께 가짜 데이터로 확인합니다.
버전 있음·없음, MDS v1·v2·혼합, MDS 없음, 정보 미제공 예시가 있습니다.
실제 검색과 연결하지 않으며 API 키 없는 검색 모드를 제공하지 않습니다.
화면 이미지 위 위치 표시는 이미지 연결과 범위 합의 후 진행합니다.
