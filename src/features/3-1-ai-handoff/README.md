# 3-1. AI로 이어서 하기

찾은 화면의 맥락을 프롬프트로 정리해 각자의 Claude/ChatGPT로 넘깁니다.

- 노션 기능 명세 DB의 "3-1. AI로 이어서 하기" 페이지를 참고합니다.
- 이 기능의 코드는 이 폴더 안에 둡니다.

## 미리보기와 연결

- 개발 서버의 `/continue-preview`에서 가짜 검색 결과로 두 가지 후속 행동을 확인할 수 있습니다.
- 검색 결과 화면을 연결할 때 `<AiHandoff result={result} />`에 기존 `SearchResult`를 넘깁니다. 프롬프트는 `screen`과 선택 항목인 `summary`를 사용합니다.
- AI 새 채팅 주소가 길이 제한을 넘으면 프롬프트를 복사하고 새 채팅을 엽니다. 브라우저가 복사를 막으면 프롬프트에서 직접 복사할 수 있습니다.
