# 3-2. MDS v2 사용 사례 비교

비슷한 상황에서 MDS v2로 만든 화면을 찾아 컴포넌트, variant, 토큰을 보여줍니다.

- 노션 기능 명세 DB의 "3-2. MDS v2 사용 사례 비교" 페이지를 참고합니다.
- 이 기능의 코드는 이 폴더 안에 둡니다.

## 미리보기와 연결

- `/mds-compare-preview`는 가짜 화면과 준비된 예시 결과를 보여 줍니다. 개인 Gemini API 키를 입력하면 같은 가짜 화면으로 AI 비교를 실행할 수 있습니다.
- 검색 결과 화면에서 `<MdsCompare result={result} screens={screens} apiKey={apiKey} />`를 사용합니다. `result`는 선택한 `SearchResult`, `screens`는 기존 비밀번호 보호 인덱스에서 이미 불러온 `IndexedScreen` 목록, `apiKey`는 브라우저에서 얻은 개인 Gemini 키입니다.
- 화면의 목적과 상태를 기준으로 비교합니다. 기준 화면의 특정 컴포넌트를 선택하면 그 컴포넌트를 MDS v2로 사용한 사례를 비교합니다. AI는 후보와 비슷한 점을 고르고, 표시할 variant·토큰·원본 링크는 인덱스에서 가져옵니다.
- 이전 인덱스의 화면 단위 토큰은 별도로 표시합니다. 컴포넌트에 연결된 토큰은 수집된 요소 정보가 있을 때 표시합니다.
