# 2-3. 다른 버전 함께 보기

PC/MO 반응형 버전과 빈 상태, 채워진 상태, 오류 같은 다른 상태 화면을 묶어 보여줍니다. (SearchResult.otherVersions)

- 노션 기능 명세 DB의 "2-3. 다른 버전 함께 보기" 페이지를 참고합니다.
- 이 기능의 코드는 이 폴더 안에 둡니다.

## 사용 및 확인

`OtherVersions`에 현재 `screen`과 선택적인 `otherVersions`를 전달합니다.
화면 관계나 PC/MO·상태를 자동으로 추측하지 않습니다. 현재 화면과 중복 항목은 파일 키·노드 ID 기준으로 제외합니다.
가짜 데이터와 확인할 수 없는 원본 URL은 링크를 비활성화합니다.

`npm run dev` 후 `/preview/other-versions`에서 가짜 데이터로 버전 있음, 정보 미전달, 빈 배열을 확인합니다.
이 페이지는 실제 검색이나 내부 인덱스를 읽지 않는 개발 예시입니다.

## 연결 전에 합의할 사항

- 다른 버전을 묶는 기준과 `otherVersions`를 채우는 담당자 (현재 2-1 검색은 이 값을 채우지 않음)
- 최종 상세 영역에서 2-2·2-3·2-4를 배치하고 연결할 담당자
- 별도 개발 확인 페이지를 유지할지 여부
